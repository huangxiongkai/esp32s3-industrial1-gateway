# 项目需求说明书（PRD v1.0）

## 一、项目背景

工业现场大量设备采用 Modbus RTU（RS485）通信，而云平台通常采用 MQTT 协议。传统 PLC 或工业网关成本较高，且扩展性有限。

本项目设计一套基于 ESP32-S3 的低成本工业物联网边缘网关，实现现场设备数据采集、协议转换、设备管理及云端接入。

> **项目一句话定位：** 将多个 Modbus RTU 从站的数据采集后，通过 MQTT 上传至 EMQX/OneNET，支持设备管理、配置管理、断网续传（W25Q64）、本地 HMI（SPI LCD + LVGL）以及 OTA 在线升级。

---

## 二、分阶段目标

### Phase 1 — MVP（基础框架）

必须完成的核心功能：

- WiFi STA 连接 + 自动重连
- MQTT 连接 EMQX + 发布/订阅
- FreeRTOS 多任务架构
- Queue 生产者-消费者通信
- cJSON 封装设备数据
- Device Manager 设备表
- Modbus RTU Master（功能码 03）
- RS485 GPIO 方向控制

**可演示成果：** MQTTX 能收到 ESP32 上报的传感器数据 JSON。

### Phase 2 — 工业通信

在 MVP 基础上增加：

- Poll Scheduler 多设备轮询调度
- 设备在线/离线检测（基于时间戳）
- 数据缓存与批量上报

**可演示成果：** PC 端 Modbus Poll 模拟从站，ESP32 轮询采集数据并上传云端。

### Phase 3 — 产品化（M8~M10）

- W25Q64 断网续传：网络中断时数据写入 SPI Flash，恢复后按时间戳补传
- 系统事件日志缓存：关键事件（上下线、OTA、故障）写入 Flash
- SPI LCD + LVGL HMI：本地工业监控界面（系统状态、设备数据、事件日志）
- OTA 固件升级：MQTT 触发、双分区回滚
- 心跳包机制
- 完整 README、测试文档、面试材料

**可演示成果：** 断网不丢数据、本地屏幕实时监控、远程升级，完整可展示的工程级项目。

## 三、功能需求

### 3.1 网络

| 需求 | 说明 |
| :--- | :--- |
| WiFi STA 模式 | 连接路由器，获取 IP |
| 自动重连 | 断线后自动尝试重连，间隔递增 |

### 3.2 MQTT

| 需求 | 说明 |
| :--- | :--- |
| 协议版本 | MQTT v3.1.1（esp_mqtt 默认） |
| QoS | 数据上报 QoS1，订阅指令 QoS0 |
| 自动重连 | 断线后自动重连 Broker |
| 心跳 | Keep-Alive 维持连接 |
| 数据格式 | JSON 封装，cJSON 库 |

### 3.3 Modbus

| 需求 | 说明 |
| :--- | :--- |
| 角色 | Master（主站） |
| 功能码 | 03（读保持寄存器） |
| 校验 | CRC16（多项式 0xA001） |
| 超时 | 响应超时 1000ms，超时重试 |

### 3.4 RS485

| 需求 | 说明 |
| :--- | :--- |
| 方向控制 | GPIO8 软件控制 DE/RE |
| 通信模式 | 半双工 |
| 发送时序 | 发送前拉高 DE，`uart_wait_tx_done` 后拉低 |

### 3.5 设备管理

| 需求 | 说明 |
| :--- | :--- |
| 多设备 | 支持多个从站设备 |
| 在线状态 | 基于时间戳判断超时离线 |
| 数据缓存 | 设备数据缓存在 device_table 中 |

### 3.6 配置管理

| 需求 | 说明 |
| :--- | :--- |
| 存储介质 | NVS Flash |
| 配置项 | WiFi SSID/密码、MQTT Broker/端口/用户名/密码、波特率、从站地址 |
| 读写 | 开机读取，修改后保存 |

---

## 四、非功能需求

| 指标 | 要求 | 说明 |
| :--- | :--- | :--- |
| 采集周期 | 1000ms | 每秒完成一轮设备轮询 |
| 连续运行 | 72 小时无崩溃 | 验证内存泄漏与稳定性 |
| RAM 占用 | < 300KB | 预留余量给 WiFi/MQTT 协议栈 |
| CPU 占用 | < 40% | 主循环不应占满 CPU |
| 可维护性 | 模块化 + 接口统一 + 日志统一 + 错误码统一 | 每个模块独立可测试 |

---

## 五、项目边界

**本项目不做：**

- Modbus TCP（仅 RTU）
- HTTPS / TLS 加密传输
- BLE / Zigbee 无线协议
- WebServer / HTTP 服务
- 本地数据库存储（SQLite 等）
- PCB 硬件设计

以上功能可作为后续扩展方向，但不纳入当前开发计划。
